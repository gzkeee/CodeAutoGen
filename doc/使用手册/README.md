## 一分钟了解这个工具

```text
┌────────────┐    ┌──────────────────┐    ┌─────────────────────┐
│  JSON 配置  │ →  │  代码生成工具 CLI   │ →  │  React + AntD 源码    │
│  （声明式）  │    │  (gen-ui)         │    │  （可直接运行）        │
└────────────┘    └──────────────────┘    └─────────────────────┘
```

- **输入**：一个 JSON 文件，声明页面有哪些组件、字段、以及组件之间的数据流动方向。
- **输出**：`index.jsx` + `components/*.jsx`，可以直接放进 Vite / CRA 项目运行。
- **核心理念**：**配置即代码**。改需求 → 改配置 → 重新生成，而不是手改大段 JSX。
