# 05 · 集成配置

生成的代码对接外部系统，主要有两个可配置点，都位于生成器的 `src/config/` 下：

| 文件 | 作用 |
|------|------|
| `src/config/request.js` | 自定义 HTTP 请求方式（`request.get/post` → 任意客户端） |
| `src/config/dict.js` | 自定义数据字典（下拉选项）的加载方式 |

> 约定：`@` 指目标工程的 `src/`。生成代码默认 `import request from '@/utils/request'`，
> 即目标工程需要提供该模块（开发期可先用 Mock）。

---

## 1. 请求层自定义（request.js）

### 1.1 配置项

```js
// src/config/request.js
const requestConfig = {
  // import 语句模板
  importStatement: "import request from '@/utils/request';",

  // 请求方法调用模板（url 三种类型各一条）
  methods: {
    load:  "request.get('{{url}}', {{config}})",
    query: "request.post('{{url}}', {{data}})",
    save:  "request.post('{{url}}', {{data}})",
  },

  // 响应中列表数据所在的字段路径
  listField: 'LIST',
};
module.exports = requestConfig;
```

### 1.2 模板变量

| 变量 | 替换为 | 使用场景 |
|------|--------|---------|
| `{{url}}` | API 地址（需自行加引号） | 全部 |
| `{{data}}` | 请求体变量名（如 `values`） | `query` / `save` |
| `{{config}}` | 配置参数变量名（如 `undefined`） | `load` |

`methods` 的 key 直接对应 `url` 字段：

| key | 对应 url | 语义 | 通常传参 |
|-----|---------|------|---------|
| `load` | `url.load` | 挂载 / 收到上游行数据时加载 | `{{config}}` |
| `query` | `url.query` | 查询提交 | `{{data}}` |
| `save` | `url.save` | 保存提交 | `{{data}}` |

`listField` 决定从响应哪里取列表：`'LIST'` → `res.LIST`；`'data.records'` → `res.data.records`。

### 1.3 常见适配

**全部使用 POST（很多后端如此）：**

```js
const requestConfig = {
  importStatement: "import api from '@/utils/api';",
  methods: {
    load:  "api.post('{{url}}', {{config}})",
    query: "api.post('{{url}}', {{data}})",
    save:  "api.post('{{url}}', {{data}})",
  },
  listField: 'data.records',
};
```

**使用 axios：**

```js
const requestConfig = {
  importStatement: "import axios from 'axios';",
  methods: {
    load:  "axios.get('{{url}}', { params: {{config}} })",
    query: "axios.get('{{url}}', { params: {{data}} })",
    save:  "axios.post('{{url}}', {{data}})",
  },
  listField: 'data.list',
};
```

**静态 Mock（无后端，开发期跑通页面）：**

```js
const requestConfig = {
  importStatement: "import mockData from '@/mock/data';",
  methods: {
    load:  "Promise.resolve(mockData['{{url}}'])",
    query: "Promise.resolve(mockData['{{url}}'])",
    save:  "Promise.resolve(mockData['{{url}}'])",
  },
  listField: 'LIST',
};
```

## 2. 数据字典自定义（dict.js）

当字段使用 `dictName` 时（动态下拉），生成的代码会自动调用字典接口加载选项：

```json
{ "name": "DEPT", "type": "Select", "label": "部门", "dictName": "SYS_DEPT" }
```

### 2.1 默认行为

生成的代码等价于：

```jsx
import DataDict from '@/utils/DataDict';           // 目标工程需提供

const [DEPT_options, setDEPT_options] = useState([]);
useEffect(() => {
  const res = await DataDict.getDict('SYS_DEPT');
  setDEPT_options(res || []);                       // res: [{ label, value }]
}, []);
```

### 2.2 配置项

```js
// src/config/dict.js
const dictConfig = {
  importStatement: "import DataDict from '@/utils/DataDict';",
  method:          "DataDict.getDict('{{dictName}}')",
  labelField:      'label',   // 返回数据中用作展示文本的字段
  valueField:      'value',   // 返回数据中用作选项值的字段
};
module.exports = dictConfig;
```

### 2.3 返回值字段不是 label/value 时

工具会自动生成 map 转换。例如后端返回 `{ id, text }`：

```js
const dictConfig = {
  importStatement: "import { getDictionary } from '@/api/dict';",
  method:          "getDictionary('{{dictName}}')",
  labelField:      'text',
  valueField:      'id',
};
```

生成代码自动变成：

```js
setDEPT_options((res || []).map(item => ({ label: item['text'], value: item['id'] })));
```

## 3. 目标工程需要提供什么？

| 模块 | 谁需要 | 说明 |
|------|--------|------|
| `@/utils/request` | 任何配了 `url` 的组件 | GET/POST 客户端，`@` 别名需在 `vite.config.js` 配置 |
| `@/utils/DataDict` | 用了 `dictName` 的字段 | `getDict(name)` 返回 `[{ label, value }]` |

两者都可以先写 Mock 让页面跑通，再替换为真实实现（参考 [01 · 快速上手](01-快速上手.md) 的 Mock 示例）。
