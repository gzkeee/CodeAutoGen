# 06 · 场景示例

本章收集完整的业务场景配置。每个场景在 `examples/` 下有对应的 JSON 文件，可直接运行：

```bash
# 生成场景 1（CRUD）
node bin/generate.js \
  -c examples/test-scenario-01-crud.json \
  -o ./output/scenario-01 \
  -n UserManage
```

| 场景 | 文件 | 覆盖能力 |
|------|------|---------|
| 1 · 标准 CRUD | `test-scenario-01-crud.json` | 查询 + 表格 + 新增/编辑弹窗 + 行点击回显 |
| 2 · 主从表 | `test-scenario-02-master-detail.json` | 查询 + 主表 + 明细表（点击主表行加载明细） |
| 3 · 级联联动 | `test-scenario-03-form-to-form.json` | Form→Form 省市区 |
| 4 · 顶层弹窗 | `test-scenario-04-top-level-modal.json` | 页面级 Modal |
| 5 · 全字段类型 | `test-scenario-05-all-field-types.json` | Input/InputNumber/DatePicker/Select/disabled |
| 6 · 容器嵌套 | `test-scenario-06-container-in-container.json` | 容器套容器 |
| 7 · 纯表格联动 | `test-scenario-07-only-tables.json` | 多个 Table 之间行联动 |
| 8 · 复杂仪表盘 | `test-scenario-08-complex-dashboard.json` | 表单 → 多容器 → 导出弹窗 |
| 9 · 动态字典 | `test-dict.json` / `test-dict-container.json` | `dictName` 动态下拉 |

## 1. 标准 CRUD（最典型）

一个容器内：**查询表单 + 用户表格 + 新增弹窗 + 编辑弹窗**。

```json
{
  "components": {
    "UserManager": {
      "components": {
        "SearchForm": {
          "Type": "Form",
          "Fields": [
            { "name": "USER_NAME", "type": "Input", "label": "用户名" },
            { "name": "STATUS", "type": "Select", "label": "状态", "options": [
              { "value": "1", "label": "启用" },
              { "value": "0", "label": "停用" }
            ]}
          ],
          "url": { "query": "/api/user/list" }
        },
        "UserTable": {
          "Type": "Table",
          "Fields": [
            { "name": "USER_NAME", "label": "用户名" },
            { "name": "DEPT_NAME", "label": "部门" },
            { "name": "STATUS", "label": "状态" }
          ],
          "url": { "load": "/api/user/page" }
        },
        "AddUserModal": {
          "Type": "Form", "Layout": "Modal",
          "Fields": [
            { "name": "USER_NAME", "type": "Input", "label": "用户名" },
            { "name": "EMAIL", "type": "Input", "label": "邮箱" }
          ],
          "url": { "save": "/api/user/add" }
        },
        "EditUserModal": {
          "Type": "Form", "Layout": "Modal",
          "Fields": [
            { "name": "USER_ID", "type": "Input", "label": "用户ID", "disabled": true },
            { "name": "USER_NAME", "type": "Input", "label": "用户名" },
            { "name": "STATUS", "type": "Select", "label": "状态", "options": [
              { "value": "1", "label": "启用" },
              { "value": "0", "label": "停用" }
            ]}
          ],
          "url": { "load": "/api/user/detail", "save": "/api/user/update" }
        }
      },
      "DataFlow": {
        "links": [
          { "from": "SearchForm", "to": "UserTable" },
          { "from": "AddUserModal", "to": "UserTable" },
          { "from": "EditUserModal", "to": "UserTable" },
          { "from": "UserTable", "to": "EditUserModal" },
          { "from": "UserTable", "to": "OUT" }
        ]
      }
    }
  },
  "DataFlow": { "links": [] }
}
```

**设计要点**：

| 要素 | 做法 |
|------|------|
| 四个子组件装进 `UserManager` 容器 | 一个文件承载整个 CRUD |
| 查询 → 表格 | `SearchForm → UserTable` |
| 新增/编辑保存后刷新表格 | `AddUserModal/EditUserModal → UserTable` |
| 点行 → 编辑回显 | `UserTable → EditUserModal`（弹窗自动打开） |
| 把选中行输出给页面父级 | `UserTable → OUT` |

**效果**：点「查询」出列表 → 点行弹出编辑并回显 → 新增/编辑保存后列表更新。

## 2. 主从表

点击主表行，下方明细表用主表行参数重新加载：

```json
{
  "components": {
    "OrderPage": {
      "components": {
        "OrderSearch": {
          "Type": "Form",
          "Fields": [
            { "name": "ORDER_NO", "type": "Input", "label": "订单号" },
            { "name": "CUSTOMER", "type": "Input", "label": "客户名称" }
          ],
          "url": { "query": "/api/order/search" }
        },
        "OrderTable": {
          "Type": "Table",
          "Fields": [
            { "name": "ORDER_NO", "label": "订单号" },
            { "name": "TOTAL_AMOUNT", "label": "总金额" }
          ],
          "url": { "load": "/api/order/list" }
        },
        "OrderDetailTable": {
          "Type": "Table",
          "Fields": [
            { "name": "PRODUCT_NAME", "label": "商品名称" },
            { "name": "QUANTITY", "label": "数量" },
            { "name": "PRICE", "label": "单价" }
          ],
          "url": { "load": "/api/order/detail" }
        }
      },
      "DataFlow": {
        "links": [
          { "from": "OrderSearch", "to": "OrderTable" },
          { "from": "OrderTable", "to": "OrderDetailTable" }
        ]
      }
    }
  },
  "DataFlow": { "links": [] }
}
```

**关键**：`OrderTable → OrderDetailTable` 触发 `tableToTable` 行为 —— 明细表
在收到上游行数据时调用 `url.load` 加载该订单的明细。

## 3. 级联联动（Form → Form）

选省份 → 联动刷新城市：

```json
"DataFlow": {
  "links": [
    { "from": "ProvinceForm", "to": "CityForm" }
  ]
}
```

**约束**：源表单（`ProvinceForm`）必须有一个 `type: "Select"` 字段。
完整配置见 `examples/test-scenario-03-form-to-form.json`。

## 4. 顶层弹窗

页面级 Modal，不放进容器：

```json
{
  "components": {
    "GlobalSearchForm": { "Type": "Form", "Fields": [], "url": { "query": "/api/search" } },
    "DataDetailModal": { "Type": "Table", "Layout": "Modal", "Fields": [] },
    "ConfigModal":    { "Type": "Form", "Layout": "Modal", "Fields": [], "url": { "save": "/api/config" } }
  },
  "DataFlow": {
    "links": [
      { "from": "GlobalSearchForm", "to": "DataDetailModal" }
    ]
  }
}
```

工具自动生成触发按钮（`source`/`standalone`）和自动打开逻辑（`target`）。

## 6. 动态字典下拉

字段用 `dictName` 声明，选项运行时从字典接口加载：

```json
{ "name": "DEPT", "type": "Select", "label": "部门", "dictName": "SYS_DEPT" }
```

生成的代码自动包含：状态 `DEPT_options`、`useEffect` 加载、`options={DEPT_options}`。
字典接口的地址与返回字段映射见 [05 · 集成配置](05-集成配置.md)。
