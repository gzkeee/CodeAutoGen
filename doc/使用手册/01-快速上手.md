# 01 · 快速上手

本章用一个**最简例子**带你走通工具的完整流程：

```text
写一个查询表单 + 结果表格的配置
        │
        ▼
一条命令生成 React + AntD 源码
        │
        ▼
放进目标工程 → 启动 → 看到一个能查询的页面
```

> 💡 目标：**10 分钟内**跑通一个「输入用户名 → 点查询 → 表格出结果」的页面。
> 这是整个工具的最小闭环，跑通它你就掌握了 80% 的用法。

---

## 1. 前置准备

| 依赖 | 说明 |
|------|------|
| Node.js ≥ 16 | 运行生成器 |
| 一个目标前端工程 | 承载生成代码，建议 Vite + React + antd（见第 4 步） |

### 1.1 安装生成器

```bash
cd <生成器项目目录>     # 即本仓库
npm install
```

---

## 2. 编写第一个配置文件

新建一个文件 `user-query.json`，内容如下：

```json
{
  "comment": "最小示例：查询表单 + 结果表格",
  "components": {
    "UserQueryForm": {
      "Type": "Form",
      "Fields": [
        { "name": "USER_NAME", "type": "Input", "label": "用户名" },
        {
          "name": "STATUS",
          "type": "Select",
          "label": "状态",
          "options": [
            { "value": "1", "label": "启用" },
            { "value": "0", "label": "停用" }
          ]
        }
      ],
      "url": { "query": "/api/user/list" }
    },
    "UserResultTable": {
      "Type": "Table",
      "Fields": [
        { "name": "USER_NAME", "label": "用户名" },
        { "name": "STATUS", "label": "状态" }
      ]
    }
  },
  "DataFlow": {
    "links": [
      { "from": "UserQueryForm", "to": "UserResultTable" }
    ]
  }
}
```

### 这个配置说了什么？

| 片段 | 含义 |
|------|------|
| `components.UserQueryForm` | 定义一个名为 `UserQueryForm` 的**查询表单**组件 |
| `Type: "Form"` | 组件类型是表单 |
| `Fields` | 表单字段：一个文本框（用户名）、一个下拉框（状态，带两个选项） |
| `url.query` | 点「查询」时调用 `POST /api/user/list`，携带表单数据 |
| `components.UserResultTable` | 定义一个**表格**组件，展示两列 |
| `DataFlow.links` | 声明数据流向：**表单提交结果 → 表格展示** |

> ⚠️ 注意：配置里**没有任何 JSX / 组件代码**。页面长什么样、请求怎么发、数据怎么传，
> 全部由工具按约定生成。

## 3. 生成代码

```bash
node bin/generate.js \
  -c ./user-query.json \
  -o ./gen/user-query \
  -n UserQueryPage
```

| 参数 | 缩写 | 说明 | 本示例 |
|------|------|------|--------|
| `--config` | `-c` | 配置文件路径 | `./user-query.json` |
| `--output` | `-o` | 代码输出目录 | `./gen/user-query` |
| `--page-name` | `-n` | 页面组件名（默认 `Page`） | `UserQueryPage` |

输出三个文件：

```text
gen/user-query/
├── index.jsx                          # 页面入口：组装两个组件
└── components/
    ├── UserQueryForm.jsx              # 查询表单（含查询/重置按钮）
    └── UserResultTable.jsx            # 结果表格
```

看一眼生成的 `UserQueryForm.jsx`（工具自动生成，无需手写）：

```jsx
const UserQueryForm = (props) => {
  const [form] = Form.useForm();
  const [loading, setLoading] = useState(false);

  // 表单项配置：由 JSON 配置生成，人工维护字段时请修改此处
  const formItems = {
    USER_NAME: {
      name: 'USER_NAME',
      label: '用户名',
      placeholder: '请输入用户名',
    },
    STATUS: {
      name: 'STATUS',
      label: '状态',
      placeholder: '请选择状态',
      options: [
        { value: '1', label: '启用' },
        { value: '0', label: '停用' },
      ],
    },
  };

  const handleQuery = async (values) => {
    setLoading(true);
    try {
      const res = await request.post('/api/user/list', values);
      if (props.setValue) {
        props.setValue(res['LIST'] || []);   // 查询结果交给父级 → 表格
      }
    } catch (error) {
      message.error('查询失败');
    } finally {
      setLoading(false);
    }
  };
  // ...
};
```

`index.jsx` 自动完成两个组件的数据接线：

```jsx
<UserQueryForm value={UserQueryFormData} setValue={setUserResultTableData} />
<UserResultTable value={UserResultTableData} />
```

> 数据流是自动接好的：表单 `setValue` → 页面 state → 表格 `value`。

## 4. 放入目标工程并运行

生成代码依赖两个运行时模块，需要在目标工程里提供（**这是唯一的对接工作**）：

- `@/utils/request` —— HTTP 客户端（别名 `@` 指 `src/`）
- `@/utils/DataDict` —— 数据字典（本例用不到，动态下拉才需要，见第 05 章）

### 4.1 准备目标工程（若还没有）

```bash
npm create vite@5 my-app -- --template react
cd my-app
npm install react@18 react-dom@18 antd@5 dayjs
# 在 vite.config.js 中配置别名 @ → ./src
# 在 main.jsx 中引入 antd/dist/reset.css
```

### 4.2 把生成代码复制进目标工程

```text
src/pages/UserQuery/
├── index.jsx
└── components/
    ├── UserQueryForm.jsx
    └── UserResultTable.jsx
```

### 4.3 提供 @/utils/request（开发期可先用 Mock）

```js
// src/utils/request.js  —— 先返回假数据，把页面跑起来
const MOCK_LIST = [
  { USER_NAME: '张三', STATUS: '1' },
  { USER_NAME: '李四', STATUS: '0' },
  { USER_NAME: '王五', STATUS: '1' },
];

const mock = (url, data) => new Promise((resolve) => {
  setTimeout(() => {
    if (url === '/api/user/list') resolve({ LIST: MOCK_LIST });
    else resolve({});
  }, 300);
});

export default {
  get: mock,
  post: mock,
};
```

### 4.4 挂载到 App 并启动

```jsx
// src/App.jsx
import UserQueryPage from './pages/UserQuery';

export default function App() {
  return <UserQueryPage />;
}
```

```bash
npm run dev     # 打开 http://localhost:5173
```

点击「查询」→ 表格出现张三 / 李四 / 王五。🎉 **第一个生成页面完成。**

## 5. 完整流程小结

```text
① 写 JSON 配置（声明组件、字段、数据流）
② 跑一条生成命令
③ 复制产物进目标工程
④ 提供 @/utils/request（接真实后端或 Mock）
⑤ 启动，看到页面
```

以后再改需求，比如给表单加一个「邮箱」查询条件：

1. 在 `Fields` 里加一行 `{ "name": "EMAIL", "type": "Input", "label": "邮箱" }`
2. 重新跑生成命令
3. 完成 —— 表单、请求参数、表格列全部自动更新

> 生成代码是可再生的：**源是 JSON 配置，产物只是中间结果**。维护配置，而不是维护 JSX。
