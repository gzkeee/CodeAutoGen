# 02 · 配置文件参考

本章是配置文件（JSON）的**完整 Schema 参考**。所有字段、类型、默认值、必填性都在这里。

---

## 1. 顶层结构

```json
{
  "comment": "可选：场景描述，不影响生成",
  "components": {
    "组件名": { /* 组件定义 */ }
  },
  "DataFlow": {
    "links": [
      { "from": "源组件", "to": "目标组件" }
    ]
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `components` | object | ✅ | 组件定义集合，**key = 组件名**（也是生成文件名），value = 组件配置 |
| `DataFlow` | object | ❌ | 数据流定义 |
| `DataFlow.links` | array | ❌ | 数据流连接数组，每条 `{ from, to }` |
| `comment` | string | ❌ | 注释，仅供人阅读 |

### 组件名规则

- 组件名同时用作**生成的文件名**和**JSX 标识符**，须为合法标识符（如 `UserQueryForm`、`OrderDetailTable`）
- 顶层组件会生成独立文件；Container 内部子组件内联在同一文件（见 [03 · 组件与字段](03-组件与字段.md)）

## 2. 组件定义

### 2.1 叶子组件（Form / Table）

```json
{
  "Type": "Form",
  "Layout": "Modal",
  "Fields": [ /* 字段定义 */ ],
  "url": { "query": "/api/xxx" }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `Type` | string | ✅ | `"Form"` 或 `"Table"`，二选一 |
| `Fields` | array | ✅ | 字段定义数组（见第 3 节） |
| `Layout` | string | ❌ | 目前仅支持 `"Modal"`，开启弹窗模式（见 [03](03-组件与字段.md) 的 Modal 节） |
| `url` | object | ❌ | API 配置（见第 4 节） |

**判断规则**：只要 `Type` 是 `Form` 或 `Table` 就是叶子组件；
如果既不是这两种类型、又没有嵌套 `components`/`DataFlow`，解析会报错。

### 2.2 容器组件（Container）

```json
{
  "HeaderPanel": {
    "components": {
      "QuickSearch": {
        "Type": "Form",
        "Fields": [ /* ... */ ],
        "url": { "query": "/api/search" }
      },
      "QuickResult": {
        "Type": "Table",
        "Fields": [ /* ... */ ]
      }
    },
    "DataFlow": {
      "links": [
        { "from": "IN", "to": "QuickSearch" },
        { "from": "QuickSearch", "to": "QuickResult" },
        { "from": "QuickResult", "to": "OUT" }
      ]
    }
  }
}
```

**识别规则**：一个组件只要同时带有 `components` + `DataFlow` 字段，就被自动识别为容器。
容器自身不需要 `Type`/`Fields`。

> 容器把所有子组件**内联**进同一个文件，子组件之间以及对外（IN/OUT）的数据传递由容器模板自动接线。

## 3. 字段定义（Fields）

```json
{
  "name": "USER_NAME",
  "type": "Input",
  "label": "用户名",
  "options": [ { "value": "1", "label": "启用" } ],
  "disabled": true,
  "dictName": "SYS_STATUS",
  "rules": [ { "required": true, "message": "请填写用户名" } ]
}
```

| 属性 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | ✅ | 字段名（生成表单的 `name`、表格的 `dataIndex`） |
| `label` | string | ✅ | 中文标签（生成表单的 `label`、表格的列标题） |
| `type` | string | ❌ | 控件类型，默认 `"Input"`（见下表） |
| `options` | array | Select 用 | 静态下拉选项，每项 `{ value, label }` |
| `dictName` | string | Select 用 | 动态字典名，与 `options` 二选一（见 [05](05-集成配置.md)） |
| `disabled` | boolean | ❌ | 是否禁用，默认 `false` |
| `rules` | array | ❌ | antd Form.Item 校验规则，原样写入配置 |

### 控件类型（`type`）

| type | 生成的控件 | 占位符约定 |
|------|-----------|-----------|
| `Input`（默认） | `<Input />` | 「请输入{label}」 |
| `Select` | `<Select />` | 「请选择{label}」 |
| `DatePicker` | `<DatePicker />` | 「请选择{label}」 |
| `InputNumber` | `<InputNumber />` | 「请输入{label}」 |

> 在 Table 的 `Fields` 里，`type` 会被忽略，只用 `name` + `label` 生成列。

## 4. API 配置（url）

```json
{
  "url": {
    "load":  "/api/user/detail",
    "query": "/api/user/list",
    "save":  "/api/user/update"
  }
}
```

| key | 适用组件 | 请求方法* | 触发时机 | 传参 |
|-----|---------|-----------|---------|------|
| `load` | Form, Table | GET | 组件挂载时自动调用（或收到上游行数据时） | 配置参数 |
| `query` | Form | POST | 点击「查询」按钮 | 表单数据 |
| `save` | Form（含 Modal 表单） | POST | 点击「保存」按钮 | 表单数据 |

\* 默认请求方法，可通过 `src/config/request.js` 完全自定义（见 [05 · 集成配置](05-集成配置.md)）。

### 一个表单可以同时配多个 url

```json
{
  "Type": "Form",
  "url": {
    "load":  "/api/user/detail",   // 打开时回显
    "save":  "/api/user/update"    // 保存
  }
}
```

## 5. 数据流定义（DataFlow）

```json
"DataFlow": {
  "links": [
    { "from": "SearchForm", "to": "UserTable" }
  ]
}
```

- `from` / `to` 引用当前层级的组件名
- 工具根据**源 / 目标组件类型**自动推导行为（`formToTable`、`tableToForm` 等）
- `IN` / `OUT` 是容器边界上的**虚拟节点**，用于内外数据交换
- 完整推导规则与每个行为的效果见 [04 · 数据流详解](04-数据流详解.md)

## 6. 校验与错误提示

工具会在以下情况报错（信息含具体组件路径）：

| 错误 | 触发 |
|------|------|
| `配置缺少 components 字段` | 顶层没有 `components` |
| `组件 "X" 缺少有效的 Type 字段` | 叶子组件没有 `Type`，且没有嵌套结构 |
| `组件 "X" 缺少 Fields 数组` | 叶子组件没有 `Fields` |
| `links[N] 缺少 from 或 to 字段` | 连接缺少端点 |
| `links[N] 引用了未定义的源/目标组件 "X"` | 连接指向不存在的组件 |
| `组件 "X" 要建立 Form→Form 连接，但未找到 type="Select" 的字段` | 级联联动缺少 Select 字段 |
